# Ballotify frontend

Nuxt 4 single-page app for organisers (dashboard) and voters (ballot and live results).

```bash
npm install
cp .env.example .env
npm run dev        # http://localhost:3000
npm run build      # production build
npm run generate   # static build in .output/public
```

See the [main README](../README.md) for full setup, configuration and deployment.
